프린터 Wi-Fi 설정

POS-8390 · 특수문자가 깨지지 않게 보냅니다

먼저 할 일

  1. 프린터 전원을 뽑고, FEED 버튼을 누른 채 다시 연결합니다
    설정 모드 안내문이 출력되면 성공입니다
  2. 이 기기의 Wi-Fi를 MYPrint에 연결합니다
    연결하면 인터넷이 끊깁니다 — 정상입니다
  3. 아래에 사무실 Wi-Fi 정보를 입력하고 보냅니다

Wi-Fi 정보

이 프린터는 2.4GHz만 지원합니다. 5GHz 전용 SSID는 붙지 않습니다.
화면에 그대로 보입니다. 입력한 글자가 맞는지 눈으로 확인하세요.

보낼 주소

SSID와 비밀번호를 입력하세요

왜 이 페이지가 필요한가

프린터 내장 설정 페이지에 비밀번호를 입력하면 느낌표가 %21로 저장됩니다. HTML 폼 전송 규격이 !를 %21로 바꾸도록 정해져 있고, 프린터 펌웨어가 그걸 되돌리지 않는 것이 원인입니다. 브라우저 잘못이 아니라 펌웨어 버그라서, 몇 번을 다시 입력해도 결과가 같습니다. 이 페이지는 폼 전송을 쓰지 않고 주소를 직접 만들어 특수문자를 원본 그대로 보냅니다.
