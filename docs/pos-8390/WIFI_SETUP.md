# POS-8390 무선 설정 — 다시 해야 할 때

2026-10-29 접속 성공. 현재 `192.168.0.8:9100`,
Wi-Fi 모듈 MAC `aa:bb:cc:dd:ee:ff` (유선 포트와 다른 칩).

## 왜 브라우저로는 안 되는가

설정 페이지에 SSID/비밀번호를 입력해도 **비밀번호에 특수문자가 있으면 영원히 실패**한다.

HTML 폼 전송 규격은 `!` 를 `%21` 로 인코딩하도록 정해져 있다. 브라우저는 규격대로
동작한 것이고, **펌웨어가 받은 값을 URL 디코딩하지 않는 것**이 버그다. 결과적으로
프린터는 비밀번호가 `secret!` 이라면 `secret%21` 이라는 9글자로 인증을 시도한다.
셀프테스트 용지에 그대로 인쇄되므로 확인할 수 있다.

## 해법

폼을 거치지 않고 느낌표를 인코딩하지 않은 생 GET 을 보낸다.

1. 프린터 전원을 뽑고, **FEED 버튼을 누른 채** 다시 연결한다 (설정 모드 안내문이 출력됨)
2. 맥북 Wi-Fi 를 `MYPrint` 에 연결한다 (인터넷이 끊긴다)
3. `tools/wifi_config.html` 을 브라우저로 열고 SSID·비밀번호를 입력해 보낸다.
   보내기 전에 화면에 뜨는 주소에서 특수문자가 그대로인지 눈으로 확인할 수 있다.

   명령줄을 선호하면 — `<SSID>` 와 `<PW>` 를 채우고 **특수문자는 그대로 둔다**:

       curl -s --http0.9 --http1.0 -g \
         'http://192.168.4.1/?dhcp_mode=0&id=<SSID>&passw=<PW>&save=SET'

4. 응답 없이 모듈이 재부팅한다. 성공하면 용지에
   `PIRNT WIFI CONNECT OK / IP:"..."` 가 인쇄된다
5. 맥북 Wi-Fi 를 원래 네트워크로 되돌린다

`ap_fetch.sh` (같은 폴더) 가 2~3단계를 명령줄에서 대신 해준다 (Wi-Fi 복구 포함).

## 보낼 수 없는 문자

브라우저가 주소에서 **반드시** 퍼센트 인코딩하는 문자들이 있다. 펌웨어는 그걸
되돌리지 못하므로, 이 문자가 비밀번호에 들어 있으면 어떤 방법으로도 전달할 수 없다.

> 공백 `"` `<` `>` `` ` `` `{` `}` `|` `\` `^` `%` `&` `#` · 그리고 ASCII 밖 문자(한글 등)

`wifi_config.html` (같은 폴더) 이 이런 문자를 발견하면 전송을 막는다. 이 경우 공유기에서
**영숫자만 쓰는 2.4GHz 게스트 SSID** 를 따로 만들어 프린터만 거기 붙이는 쪽이 확실하다.

느낌표를 비롯한 나머지 특수문자(`!` `@` `$` `*` `(` `)` `-` `_` `~` `'` 등)는 그대로 전달된다.

## 걸려 넘어지기 쉬운 곳

**웹서버가 HTTP/0.9 로 답한다.** 상태줄도 헤더도 없이 본문만 보낸다. 그래서
평범한 `curl` 은 `(1) Received HTTP/0.9 when not allowed` 로 거부하고, `nc` 로 만든
생 요청도 빈 응답을 받는다. `--http0.9` 가 반드시 필요하다. 브라우저만 되고
명령줄은 전부 안 되는 것처럼 보여서 오래 헤맸다.

**동시 접속을 하나만 받는다.** 요청을 연달아 보내면 웹서버가 죽고 포트까지 닫힌다.
전원을 다시 넣어야 살아난다. 한 번에 하나씩, 간격을 두고 보낼 것.

**맥북 Wi-Fi 복구를 SSID 이름에 의존하지 말 것.** 위치 권한이 없으면
`networksetup -getairportnetwork` 가 SSID 대신
`"You are not associated with an AirPort network."` 라는 문장을 돌려준다.
그 값으로 복구를 시도하면 맥북이 AP 에 갇힌다. 대신 AP 를 기억 목록에서 지우고
Wi-Fi 전원을 껐다 켜서 키체인에 저장된 네트워크로 자동 재접속시킨다.

## 남은 일

공유기에서 Wi-Fi 모듈 MAC 에 **DHCP 고정 할당**을 걸 것 (예: `aa:bb:cc:dd:ee:ff`).
실제 MAC 은 접속 성공 후 `arp -n <프린터IP>` 로 확인한다. 유선 포트와 다른 칩이라
주소도 다르다.
안 걸면 IP 가 바뀌어 다시 찾아야 한다.
